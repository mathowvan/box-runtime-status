# 运行环境状态页（草稿）

这是一个使用 Python 标准库的只读状态页草稿，参考了 ACLClouds 的状态页结构，目标是便于之后评估能否在 Box workspace 运行。它不依赖第三方包，也不包含 Box 专属路径、地址或配置。

## 显示内容

- 服务进程运行时长和 UTC 快照时间。
- 主机名，以及通过 UDP 路由选择确定的本地 IP（不发送数据包）。
- 公网出口 IP：通过 HTTPS 向固定的 `api.ipify.org` 发出 IP 查询；只发送查询请求，不发送环境变量或其他运行数据，超时为 2 秒。
- 固定白名单中的环境配置：`SERVER_PORT`（仅有效端口号）、`PYTHONUNBUFFERED` 和 `PYTHONDONTWRITEBYTECODE`（仅标准布尔值，转换为布尔型）、`TZ`（仅有效时区名称）。不匹配预期格式的值会被省略。
- Linux cgroup 中可读的内存使用量与限制。
- 当前根挂载视图的磁盘已用、可用和总量。

页面和 JSON 接口均返回上述字段。环境采集只读取列出的四个变量，不枚举完整环境，不读取 `.env`，也不返回文件路径、系统/内核版本、进程列表或命令版本。公网 IP 查询会让 `api.ipify.org` 看到服务端发出的请求及其出口 IP；其他状态采集不会调用外部服务。缺失或不可读的值以 `null` /“不可用”表示。状态快照最多缓存 5 秒。

## 接口

| 路径 | 返回内容 |
|---|---|
| `/` | 中文暗色 HTML 页面 |
| `/api/status` | JSON 状态快照 |
| `/healthz` | 轻量存活检查 `ok` |

## 本地运行与测试

```sh
SERVER_PORT=8000 python3 -I -B -u runtime_status.py
```

端口通过 `SERVER_PORT` 设置，默认 `8000`，有效范围为 1–65535。程序绑定 `0.0.0.0`，用于接受端口转发平台的请求。状态页仅展示并校验固定白名单中的环境变量；服务启动时也只读取 `SERVER_PORT` 作为端口配置。

```sh
python3 -m py_compile runtime_status.py test_runtime_status.py
python3 -m unittest -v
```

测试中的主机、网络、环境、磁盘/cgroup 和 HTTP 状态数据均使用模拟值，不查询公网 IP 服务、不查询 Box，也不读取真实磁盘/cgroup 状态。

## 发布或接入平台前

当前草稿没有应用层登录或访问令牌：若运行平台把该端口公开，访客可读取主机名、IP 地址、允许展示的环境配置及聚合资源指标。不要在确认 Box 的访问控制方式前公开运行此服务；接入前应由所有者决定是否依赖平台自身的访问控制，或先为页面/API 增加认证。此目录目前仅供代码和测试审阅，不表示已访问 Box、已部署或已发布公开仓库。
